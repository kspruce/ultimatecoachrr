Four tests that matter for ultimate, how to run them and how to get better.

Fitness
Running a test day
  • Test three times a season: pre-season, mid-season and a few weeks before your main tournament.
  • Do all four in one session, about an hour, in this order: broad jump, 10 m sprint, pro agility, then the Yo-Yo last because it empties the tank.
  • Warm up properly first: 10 minutes of jogging, dynamic stretches and a few build-up sprints.
  • Same surface, same shoes and the same timing method each time, so results are comparable.
