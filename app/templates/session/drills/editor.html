Keyboard Shortcuts
Tools
  • V Select
  • O Offense Player
  • D Defense Player
  • F Disc
  • C Cone
  • L Cut
  • R Throw
  • M Movement (dotted)
  • P Freehand
  • A Shaded area
  • T Text
Arrows
  • Drag for a straight arrow
  • Or click points, then double-click or Enter
  • Shift Straight angles
  • Drag a selected arrow's handles to reshape it
  • Arrows drawn from a player move with them
Touch
  • Tap to place; drag a selected player's blue handle to draw their cut
  • Long-press for the menu
  • Two fingers: zoom and pan
View
  • Scroll, or + / -: zoom
  • 0 Fit to screen
  • Middle-drag or Alt-drag: pan
Actions
  • Delete Delete Selected
  • Ctrl + S Save Drill
  • Ctrl + Z Undo
  • Ctrl + Y Redo
  • Ctrl + C / V Copy / paste
  • Ctrl + D Duplicate
  • Arrow keys: nudge (Shift for 5 yards)
  • Esc Back to Select
  • Double-click text to edit it
Stages
  • [ / ] Previous / next stage
  • Space Play / pause
  • Esc Back to editing
