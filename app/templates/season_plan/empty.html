Importing a plan

A season plan is imported from a markdown export (a folder with manifest.json and one file per tab) on the server:

flask import-season-plan path/to/export --team {{ current_team.slug if current_team else '<team-slug>' }} --dry-run

Run it with --dry-run first to check what it found, then without to import.
