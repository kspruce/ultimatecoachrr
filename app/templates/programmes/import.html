Bring an existing plan in from a spreadsheet using the documented format. Nothing is created until you've checked the preview and fixed any errors.

The format

One row per exercise (or per session, or per rest week), with the track, week and session it belongs to. Blank track, week or session cells carry on from the row above. Tests go in a second sheet or file. Full details: docs/PROGRAMME_IMPORT.md.
