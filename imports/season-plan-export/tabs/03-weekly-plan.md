# Weekly plan

Every week pairs a fundamental skill in the joint session with the tactic that uses it in each team's split session. Weeks run in themed blocks of two to three weeks, built around the event calendar. Dates are week commencing (Monday), starting 4 October 2027; events use this season's dates as a guide until 2028 dates are published. The 2s column is a suggestion for the 2s captains, who run their own sessions.

## How the weeks link

The joint session teaches the skill; the split session uses it straight away in each team's own tactics. The 2s run a simpler playbook, so their split theme is usually the more basic form of the 1s' theme.

|  | 1s playbook | 2s playbook |
| --- | --- | --- |
| Main offence | Horizontal stack, with a dominator set from it | Vertical stack, cutting from the back |
| Second offence | Vertical stack, cutting from the back or the front | Vertical stack cutting from the front |
| Zone offence | Around, through and over; endzone calls Endzone and Spread | Around and through: bucket and swing; Endzone call (Spread optional) |
| Main defence | Person defence: back shoulder, hard-working forces, poach and clog near the disc; called switches from Phase 3 | The same, with more emphasis on poaching and clogging to close gaps; called switches from Phase 3 |
| Zones | Bull zone (2-3-2 / 2-4-1) forcing middle; arrowhead with a line trap in wind | Basic Bull zone; arrowhead in wind (previewed in Phase 3, in full in Phase 4) |
| Resets | Positive and negative resets, Jedi | Dump and swing, Five Frisbee Habits |

The 1s and 2s split themes in each week can run side by side on neighbouring pitches, so a coach can move between them.

The three trial sessions are built from games the club already knows, so selection rewards improvement and decisions, not just familiarity with a system. Squads are announced after the Solent warm-up.
